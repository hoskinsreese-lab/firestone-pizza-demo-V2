# Firestone Pizza V2 — Hoskin's Designs portfolio concept

This is a fictional restaurant website. It does not accept payments or submit real orders.

## Guaranteed image replacement
The image alongside **WE DON'T DO AVERAGE** is now `pizza-feature.svg`, a pizza illustration INCLUDED in this ZIP. It does not depend on an external image URL, so it cannot turn back into the unrelated office image due to caching or a third-party photo link.

## Publish as a fresh website
1. Create a PUBLIC GitHub repository named `firestone-pizza-v2`.
2. Extract this ZIP on your computer.
3. Upload the files `index.html`, `styles.css`, `script.js`, and `pizza-feature.svg` to the repository root. You may also upload `README.md`.
4. In Settings > Pages, select Deploy from a branch, `main`, `/ (root)`, and Save.
5. Wait for deployment, then open `https://hoskinsreese-lab.github.io/firestone-pizza-v2/`.

## Notes
The pizza menu and cart are for demonstration only. Real ordering requires integration with the restaurant's own POS/ordering platform (e.g., Square or Toast).
